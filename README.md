# APTITUDE WP2

This repository holds specifications and prototypes for APTITUDE WP2.

## T2.3.1

Directory `T2.3.1/` hosts the Registration API/database backend
developed for APTITUDE T2.3.1.

Contents:
* `T2.3.1/product.md`: the full product description of T2.3.1
* `T2.3.1/openapi.json`: OpenAPI spec
* `T2.3.1/api.md`: a human-readable description of the OpenAPI spec
* `T2.3.1/product_ui.md`: a product description as viewed from a UI
  using the backend
* `T2.3.1/database.md`: the database model definition
